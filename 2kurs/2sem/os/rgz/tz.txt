В качестве раздела (тома), в котором размешается файловая структура, используется
двоичный файл произвольного доступа (Cprog 9.4, 9.5). Размер задается при начальном
форматировании (инициализации ФС) и записывается файл требуемого размера. При разработке
на С/C++ используются базовые функции библиотеки в/в для работы с файлами произвольного
доступа. При разработке на Java – RandomAccessFile
https://docs.oracle.com/en/java/javase/17/docs/api/java.base/java/io/RandomAccessFile.html
РГР представляет собой разработку системы управления файлами с заданным набором
параметров.
Физический уровень. Распределение носителя:
1
2 разделами (блоками переменной размерности)
3 кластерами (блоками фиксированной размерности)
Структура данных свободных блоков:
1 Битовая карта
2 Список свободных кластеров (разделов)
3 Список с массивом указателей на кластеры (разделы)
4 Упорядоченный по длине список разделов
5 Дерево с массивами указателей на кластеры (разделы)
6 FAT
Базовый уровень. Наличие индексного файла
1 Индексный файл имеется (содержит дескрипторы файлов, каталогов, файла свободного
пространства, индексного файла (самого себя). Начальная запись носителя содержит
смещение начала индексного файла.
2 Индексный файл отсутствует. Начальная запись носителя содержит параметры файла
(описания) свободного пространства и корневого каталога.
Размещение файла:
1 FAT
2 Список кластеров (разделов)
3 Список с массивом указателей на кластеры (разделы)
4 Дерево с массивами указателей на кластеры и их размеры.
5 Дерево UNIX
Логический уровень. Система каталогов (папок).
1 Неупорядоченный список имен файлов
2 Упорядоченный по алфавиту список имен файлов.
Символьный уровень. Спецификация пути файла. Функции open,close,seek,read,write записей
произвольный длины с буферизацией. Функции remove, rename, create_dir, remove_dir для
файлов и каталогов.
Прикладной уровень. Утилита управления носителем:
1 Форматирование (создание файловой структуры). Просмотр каталогов и файлов.
2 Экспорт/импорт файлов, папок, носителя.
3 Дефрагментация и сжатие файлов.
