## 2. Цель работы

Реализовать программу, демонстрирующую работу дерева процессов, использующих разделяемую память и семафоры для синхронизации при выполнении рекурсивной сортировки массива.

## 3. Основные требования к программе

### 3.1 Архитектура программы
- Программа должна создавать дерево процессов заданной глубины
- Корневой процесс создает разделяемую память и заполняет массив данными
- Каждый процесс-родитель создает двух потомков для сортировки своих половин массива
- Процессы общаются через разделяемую память (без каналов и сокетов)
- Синхронизация завершения потомков осуществляется через семафоры
- При достижении максимальной глубины рекурсии сортировка выполняется локально

### 3.2 Алгоритм сортировки (72-01)
- Реализовать сортировку массива рекурсивным разделением:
  - Массив делится на две примерно равные части
  - Каждая часть сортируется независимо
  - Слияние не требуется (в отличие от сортировки слиянием)
  - В качестве локальной сортировки использовать любой простой алгоритм (вставками, пузырьком и т.п.)

### 3.3 Требования к входным данным
- Размер массива задается пользователем (рекомендуется от 100 000 до 10 000 000 элементов)
- Массив заполняется случайными числами
- Предусмотреть возможность генерации тестовых данных для проверки корректности

## 4. Детальная спецификация компонентов

### 4.1 Разделяемая память
```c
// Структура данных в разделяемой памяти
struct SharedMemory {
    int *array;           // Указатель на массив данных
    int size;             // Размер массива
    int max_depth;        // Максимальная глубина рекурсии
    sem_t *semaphores;    // Массив семафоров для синхронизации
    TaskParams *tasks;    // Параметры задач для потомков
};

// Параметры задачи для потомка
struct TaskParams {
    int left;             // Левая граница интервала
    int right;            // Правая граница интервала
    int depth;            // Текущая глубина рекурсии
    int child_sem_index;  // Индекс семафора для оповещения родителя
    pid_t child_pid;      // PID потомка (для отладки)
};
```

### 4.2 Семафоры
- Использовать именованные семафоры POSIX (`sem_open`, `sem_wait`, `sem_post`, `sem_close`, `sem_unlink`)
- Для каждого потомка создавать отдельный семафор
- Имена семафоров формировать уникально (например, на основе PID родителя и индекса потомка)

### 4.3 Процессы
- Создание процессов через `fork()`
- Корневой процесс: PID известен, создает разделяемую память
- Дочерние процессы: наследуют доступ к разделяемой памяти
- Завершение процессов через `exit()` с кодом возврата

## 5. Алгоритм работы программы

### 5.1 Инициализация (корневой процесс)
1. Получить от пользователя:
   - Размер массива N
   - Максимальную глубину рекурсии D
2. Создать разделяемую память (`shm_open`, `ftruncate`, `mmap`)
3. Заполнить массив случайными числами
4. Инициализировать структуры синхронизации
5. Запустить таймер
6. Вызвать `process_sort(0, N-1, 0, NULL)`

### 5.2 Функция process_sort(left, right, depth, parent_sem)
```c
void process_sort(int left, int right, int depth, sem_t *parent_sem) {
    // 1. Проверка базовых условий
    if (left >= right) {
        if (parent_sem) sem_post(parent_sem);
        return;
    }
    
    // 2. Если достигнута максимальная глубина или массив маленький
    if (depth >= max_depth || (right - left) < THRESHOLD) {
        local_sort(shared_array, left, right);
        if (parent_sem) sem_post(parent_sem);
        return;
    }
    
    // 3. Разделение массива
    int mid = left + (right - left) / 2;
    
    // 4. Создание семафоров для потомков
    char sem_name1[64], sem_name2[64];
    sprintf(sem_name1, "/sem_%d_%d", getpid(), 0);
    sprintf(sem_name2, "/sem_%d_%d", getpid(), 1);
    
    sem_t *sem1 = sem_open(sem_name1, O_CREAT, 0644, 0);
    sem_t *sem2 = sem_open(sem_name2, O_CREAT, 0644, 0);
    
    // 5. Создание первого потомка
    pid_t pid1 = fork();
    if (pid1 == 0) {
        // Потомок 1
        process_sort(left, mid, depth + 1, sem1);
        exit(0);
    }
    
    // 6. Создание второго потомка
    pid_t pid2 = fork();
    if (pid2 == 0) {
        // Потомок 2
        process_sort(mid + 1, right, depth + 1, sem2);
        exit(0);
    }
    
    // 7. Ожидание завершения потомков через семафоры
    sem_wait(sem1);
    sem_wait(sem2);
    
    // 8. Очистка семафоров
    sem_close(sem1);
    sem_close(sem2);
    sem_unlink(sem_name1);
    sem_unlink(sem_name2);
    
    // 9. Ожидание завершения процессов (для избежания зомби)
    waitpid(pid1, NULL, 0);
    waitpid(pid2, NULL, 0);
    
    // 10. Сигнал родителю (если есть)
    if (parent_sem) sem_post(parent_sem);
}
```

### 5.3 Локальная сортировка
```c
void local_sort(int arr[], int left, int right) {
    // Реализация простой сортировки (например, вставками)
    for (int i = left + 1; i <= right; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= left && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}
```

## 7. Тестирование

### 7.1 Режимы тестирования
1. **Режим 0 (без процессов):** `max_depth = 0` - только локальная сортировка
2. **Режим 1 уровень:** `max_depth = 1` - корень создает двух потомков
3. **Режим 2 уровня:** `max_depth = 2` - дерево из 7 процессов (1+2+4)
4. **Режим 3 уровня:** `max_depth = 3` - дерево из 15 процессов

### 7.2 Проверка корректности
- Сравнить результат сортировки с эталонной (например, `qsort` из стандартной библиотеки)
- Проверить на разных размерах массива: 100, 1000, 10000, 100000, 1000000
- Проверить на разных типах данных: упорядоченные, обратно упорядоченные, случайные

## 8. Обработка ошибок
