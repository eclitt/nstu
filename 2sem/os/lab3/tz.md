# Задание для AI: Лабораторная работа №3

## Тема
Процессы. Неименованные каналы (POSIX, C).

## Вариант
**Тип 3:** Рекурсивные алгоритмы, два потомка или более.  
**14 72-02:** "Быстрая" сортировка (Quick Sort).

## Задача
Разработать программу на C (POSIX) для рекурсивного создания дерева процессов, которые совместно выполняют быструю сортировку массива. Передача данных между процессами должна осуществляться через **неименованные каналы (pipe)**. Необходимо реализовать:

1. Родительский процесс создаёт исходный массив целых чисел (размер >10, например 20 элементов).
2. Родитель создаёт два дочерних процесса.
3. Каждый дочерний процесс получает через pipe свою часть массива (левая часть < опорного элемента, правая > опорного).
4. Процессы рекурсивно создают своих потомков до заданной глубины рекурсии (глубина передаётся как аргумент командной строки).
5. Отсортированные части возвращаются родителю через pipe.
6. Родитель собирает и выводит отсортированный массив.

## Требования к реализации
- Использовать только POSIX: `fork()`, `pipe()`, `dup2()`, `read()`, `write()`, `wait()`.
- Не использовать `popen()`, `system()`, файлы для обмена.
- Синхронизация через закрытие ненужных концов каналов и `wait()`.
- Глубина рекурсии ограничена (например, до 3-4 уровней для наглядности).
- Код должен быть прокомментирован.
