# ЛР 1. Методические указания для студента

## Цель работы

Научиться выделять трафик заданного прикладного протокола, определять
его структуру и отображать содержимое пакетов в Wireshark: от display-
фильтра по байтам до полноценного Lua-диссектора с собственными полями.

Связанные лекции: лекция 1 (DPI и наблюдаемость трафика),
лекция 5 (сокеты, кадрирование сообщений).

## Что понадобится

- Wireshark 3.6 или новее (Lua включен в стандартную сборку);
- Python 3.8+ (или компилятор C/C++ по выбору);
- права на захват трафика loopback-интерфейса
  (в Linux: sudo или группа wireshark).

## Как установить Lua-диссектор

1. Откройте Wireshark, меню Help > About Wireshark > Folders.
2. Найдите строку Personal Lua Plugins и создайте этот каталог,
   если его нет.
3. Скопируйте туда ваш .lua файл и перезапустите Wireshark
   (или нажмите Ctrl+Shift+L для перезагрузки Lua-скриптов).
4. Альтернатива без установки: wireshark -X lua_script:uninet.lua.

Проверка: откройте capture.pcapng; пакеты на порту варианта должны
отображаться с протоколом UNI-NET.

## Типичные грабли

- TCP не сохраняет границы сообщений: recv(1024) может вернуть
  половину сообщения или полтора. Используйте чтение точного числа
  байтов (recv_exactly).
- Поля больше одного байта передаются в сетевом порядке байтов:
  struct.pack(">HBBHH", ...), а не "<HBBHH".
- Если Wireshark не видит протокол, проверьте: порт в диссекторе
  совпадает с портом сервера; скрипт перезагружен (Ctrl+Shift+L);
  нет ошибок Lua (окно появляется при запуске).
- Захватывайте на loopback-интерфейсе (lo), а не на внешнем,
  если клиент и сервер на одной машине.

## Критерии оценки

Работа оценивается по стандартной шкале курса. Без успешной защиты (объяснение
кода и живое изменение по указанию преподавателя) работа не засчитывается.
